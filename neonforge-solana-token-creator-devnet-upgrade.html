Sistem akan memeriksa mint dan authority di network aktif sebelum revoke.

SYSTEM INFORMATION

NEONFORGE / On-chain build

Transaksi SPL Token memerlukan provider wallet yang kompatibel, HTTPS, RPC yang tersedia, dan persetujuan eksplisit di wallet. Semua biaya Mainnet dibayar dari wallet kamu.

Metadata memerlukan URI JSON HTTPS yang sudah di-host; unggah logo dan pembuatan URI tidak dilakukan otomatis oleh halaman ini. Transaksi harus diuji di Devnet sebelum Mainnet. Jangan pernah memasukkan seed phrase atau private key.
